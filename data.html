PARTIE 1Programmation classique ou machine learning

Deux manières opposées de résoudre un problème : écrire les règles soi-même, ou laisser la machine les apprendre à partir d'exemples.

Programmation classiqueMachine learning (ML)
LogiqueRule-based : basée sur des règlesLearning-based : basée sur l'apprentissage
RaisonnementApproche déductive (↓)Approche inductive (↑)
En clairDéductif ou inductif ?

Déductif : on part de règles générales écrites par un humain et on les applique aux cas. Inductif : on part de nombreux cas (les données) et on en tire des règles générales.

PARTIE 2Vocabulaire et objectif du ML

Trois mots-clés à connaître avant tout le reste.

ML keywords

Instance, Feature et Target Variable.

  • Instance : un exemple, une ligne de données (un client, un logement, une transaction).
  • Feature : une caractéristique de cet exemple (âge, surface, montant).
  • Target variable : la valeur qu'on cherche à prédire.
ML objective

Prédire la valeur à partir d'autres valeurs corrélées (Predict the value from other correlated values).

À quoi ça sert

Le ML sert dans la prédiction et l'optimisation énergétique.

Sous le capot

Le ML et ses algorithmes transforment les données en vecteurs, puis manipulent ces vecteurs pour prédire, calculer et optimiser (transforming data into vectors and manipulating the vectors to predict, calculate and optimize).

PARTIE 3Entraîner et évaluer un modèle

On sépare les données en deux : une partie pour apprendre, une partie pour vérifier que le modèle sait généraliser.

Train · 70 %
Test · 30 %
  1. Train data set : 70 % d'exemples étiquetés (labelled examples). Les features et la classe entrent dans le ML, qui apprend.
  2. Test data set : 30 % d'exemples étiquetés. Le modèle prédit, puis on compare avec la vraie classe.
  3. Évaluation du modèle : on mesure à quel point les prédictions sont proches de la réalité.
Cost function

La fonction de coût est la distance entre le rond vert et la croix orange (the distance between the green circle and the orange cross). Plus cette distance est petite, meilleur est le modèle.

En clairPourquoi un jeu de test ?

Un modèle évalué sur les données qu'il a déjà vues paraîtrait toujours bon. Le jeu de test, qu'il n'a jamais vu, dit s'il fonctionnera sur de nouveaux cas.

PARTIE 5Les 3 types d'apprentissage

Le ML se divise en trois familles, selon ce qu'on donne à la machine pour apprendre.

① SupervisedSupervisé

Exemples + target.

Orienté tâche (task driven). C'est le plus simple (the more simple).

Ex. : classification et régression.

② UnsupervisedNon supervisé

Plus difficile, car on ne sait pas exactement sur quoi on travaille.

Ex. : clustering et réduction de dimension (dimensionality reduction).

③ ReinforcementPar renforcement

Troisième famille citée dans le cours. Les notes de cette séance n'en détaillent pas le fonctionnement.

À vérifier

Sur la photo, la mention « (continues des variables) » à côté de la réduction de dimension est difficile à lire. À relire dans tes notes.

En clairClassification ou régression ?

Classification : prédire une catégorie (client fidèle ou non). Régression : prédire un nombre (le prix d'un logement).

PARTIE 6Les algorithmes à retenir

Les data scientists peuvent dire quelle est la meilleure solution parmi celles qu'ils ont testées. Mais il peut y en avoir une meilleure qu'ils n'ont pas testée !

Random Forest

Le réflexe du praticien

« Quel que soit le problème que j'ai, j'utilise d'abord une Random Forest, puis j'avance » (whatever the problem I have, first I used a random forest and then I proceed).

K-Nearest Neighbors (K-NN)

Principe

Le résultat dépend de la valeur de k. Par exemple, avec k = 5 : on regarde les 5 ronds les plus proches de notre épicentre.

Type d'apprentissage

K-NN est du supervised learning.

K-means

Principe

Un cluster se forme autour d'un point barycentre.

Itération

On commence avec un point aléatoire très loin du barycentre, puis on itère jusqu'à obtenir un « plateau », c'est-à-dire une stabilité.

Elbow method

La méthode du coude sert à trouver le K optimal.

Type d'apprentissage

K-means est un algorithme d'unsupervised learning qui regroupe les points de données similaires en k clusters.

Le piège des deux « K »

K-means (non supervisé, il crée des groupes) et K-NN (supervisé, il prédit à partir de voisins étiquetés) portent tous deux un « k », mais ce ne sont pas la même chose.

PARTIE 9K-means en Python (k = 5)

Générer 300 points, les regrouper en 5 clusters, puis tracer le résultat avec les centroïdes.

# Imports nécessaires
import matplotlib.pyplot as plt
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans

k = 5              # nombre de clusters
n_samples = 300    # nombre de points
cluster_std = 1.2  # dispersion des groupes

# Données : 300 points 2D répartis en k groupes
X, _ = make_blobs(n_samples=n_samples, centers=k,
                  cluster_std=cluster_std, random_state=42)

# Modèle : 10 initialisations, on garde la meilleure
km = KMeans(n_clusters=k, n_init=10, random_state=42)
labels = km.fit_predict(X)     # cluster de chaque point
centers = km.cluster_centers_  # les 5 centroïdes

# Graphique
plt.scatter(X[:, 0], X[:, 1], c=labels, alpha=0.6)
plt.scatter(centers[:, 0], centers[:, 1],
            c="red", marker="X", s=300)
plt.title(f"K-means avec k={k}")
plt.xlabel("x1")
plt.ylabel("x2")
plt.tight_layout()
plt.show()

Ce que fait chaque partie

Les paramètres

k=5 est le nombre de clusters, n_samples=300 le nombre de points, cluster_std=1.2 la dispersion de chaque groupe. Plus elle est grande, plus les groupes se mélangent.

make_blobs

Génère 300 points en 2 dimensions répartis en k groupes. X contient les points. Le _ reçoit les vrais labels, qu'on ignore volontairement : K-means est non supervisé. random_state=42 rend le résultat reproductible.

KMeans

n_clusters=k fixe le nombre de groupes. n_init=10 lance 10 initialisations différentes et garde la meilleure, ce qui évite de tomber sur un mauvais départ.

fit_predict et cluster_centers_

fit_predict(X) entraîne le modèle et renvoie le cluster de chaque point (labels). cluster_centers_ donne les 5 centroïdes, c'est-à-dire les barycentres des clusters.

Le graphique

Le premier scatter colore chaque point selon son cluster (c=labels, alpha=0.6 pour la transparence). Le second ajoute les centroïdes en grosses croix rouges (marker="X", s=300).

PARTIE 10La méthode du coude en Python

Comment choisir k quand on ne le connaît pas : on teste plusieurs valeurs et on regarde où l'erreur cesse de baisser vite.

import matplotlib.pyplot as plt
import pandas as pd
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans

# 300 points avec 3 vrais groupes : le bon k est donc 3
X, _ = make_blobs(n_samples=300, centers=3,
                  cluster_std=1.2, random_state=42)

# Un K-means par valeur de k, de 1 à 6
results = []
for k in range(1, 7):
    model = KMeans(n_clusters=k, n_init=10, random_state=42).fit(X)
    cost = int(round(model.inertia_, 0))   # erreur arrondie
    results.append((k, cost))

df = pd.DataFrame(results, columns=["k", "Error (inertia)"])
ks = df["k"]
errors = df["Error (inertia)"]

# Courbe
plt.plot(ks, errors, marker="o")
plt.xticks(ks)                 # uniquement des entiers
plt.xlabel("k (nombre de clusters)")
plt.ylabel("Error (inertia)")
plt.title("Méthode du coude")
plt.grid(True)

# Annotation du coude, fixé à la main
elbow_k = 3
elbow_error = df.loc[df["k"] == elbow_k, "Error (inertia)"].values[0]
plt.scatter([elbow_k], [elbow_error], c="red", marker="X",
            s=200, label=f"Coude : k={elbow_k}")
plt.legend()
plt.show()
inertia_

La somme des distances au carré entre chaque point et le centroïde de son cluster. C'est l'« erreur » du modèle : plus elle est faible, plus les clusters sont compacts.

La boucle

for k in range(1, 7) entraîne un K-means pour chaque valeur de k. int(round(..., 0)) arrondit l'inertie à l'entier. Les couples (k, cost) sont rangés dans results, puis mis dans un tableau pandas.

La courbe

plt.plot(ks, errors, marker="o") trace la courbe, xticks(ks) n'affiche que des entiers sur l'axe, grid(True) ajoute le quadrillage.

Attention

elbow_k = 3 est écrit à la main : le code ne détecte pas le coude tout seul. Il le marque seulement sur le graphique, parce qu'on sait déjà qu'il y a 3 groupes.

Lire le résultat

Le coude

L'inertie baisse toujours quand k augmente. Elle vaudrait 0 avec k = 300, un cluster par point, ce qui n'a aucun intérêt. Le coude est l'endroit où la baisse devient faible. Ici, la chute est forte de k = 1 à k = 3, puis les gains sont minimes : le bon k est 3.

Sur des données réelles

Le coude est souvent ambigu, parce que la courbe descend sans cassure nette. On le complète alors avec le score de silhouette, qui mesure à quel point chaque point est bien rangé dans son cluster.
